# Jarvis Voice Assistant 🎙️

A lightweight Python voice assistant that listens for a wake word and executes tasks like opening websites.

## 🚀 Features
- Wake-word detection ("Jarvis")
- Voice synthesis via `gTTS` and `pygame`
- Dynamic URL parsing and web opening

## 📦 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/YOUR_USERNAME/jarvis-voice-assistant.git](https://github.com/YOUR_USERNAME/jarvis-voice-assistant.git)
   cd jarvis-voice-assistant
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

## 🎯 Usage
Run the assistant:
```bash
python main.py
```

Speak **"Jarvis"** to activate, then state a command like:
- `"Open Google"`
- `"Open Stack Overflow"`
- `"Open Wikipedia dot org"`
